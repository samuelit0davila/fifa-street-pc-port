# Contributing

This project is experimental. Useful contributions include installation logs, reproducible bug reports, hardware testing and small, documented compatibility fixes.

Before changing code, read the [current status](docs/STATUS.md) and [build guide](docs/BUILDING.md). Describe the problem, the change and the evidence used to validate it. Keep title-specific changes separate from general SDK changes where practical.

Do not submit ISOs, XEX files, extracted game archives, generated guest code or locally recompiled game binaries. Use your own game copy for testing and keep those files outside Git.

For reports, include the installer version, Windows version, CPU, GPU, driver, game region/build, the steps to reproduce and the relevant text log. Screenshots should be genuine captures from this project. Remove private paths or other personal information before posting if desired.

Original project contributions are accepted under MIT. Changes to third-party or derived SDK code must preserve the applicable upstream notices and licenses.
