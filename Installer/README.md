# Installer source

This folder contains the English Windows installer, its local-build script and the public recompilation template. The installer takes a user's ISO and produces the game locally.

Read [the build guide](../docs/BUILDING.md) for SDK preparation and single-file packaging. Supply `tools/extract-xiso.exe` locally. `bundle.zip` is generated by `BuildSetup.ps1` and must not be committed.

The GUI validates the ISO, copies extracted data, applies the start-screen/main-menu credits, then compiles both game modules. `CreditPatch.cs` verifies supported menu hashes and rebuilds the companion archive index. The small embedded recipe contains credit differences, not complete proprietary archives.

The third-party LZX decoder retains its Ms-PL notice. Original installer source uses the root MIT license. Game data, original executables and generated guest code are excluded.
