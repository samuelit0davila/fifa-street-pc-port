# Installer source

This folder contains the English Windows installer, its local-build script and the public recompilation template. The installer takes a user's own Xbox 360 FIFA Street ISO and produces the PC build locally.

Read [the build guide](../docs/BUILDING.md) for SDK preparation and single-file packaging. Supply `tools/extract-xiso.exe` locally. `bundle.zip` is generated by `BuildSetup.ps1` and must not be committed.

The GUI validates the ISO, copies extracted data, applies the start-screen/main-menu credits, then recompiles the main executable and the required guest modules.

The current pipeline builds:

- `fifastreet.exe`
- `fifastreet_fifadllzf_xex.dll`
- `fifastreet_FootballCompEngzf_xex.dll`

`FootballCompEngzf.xex.dll` is discovered in the game's DLC tree and is required for the validated World Tour flow.

The v0.3.0 package includes validated **Direct3D 12** and **Vulkan** ReXGlue backend pairs under `Game/Backends/`. `BuildSetup.ps1` and `BuildFifaStreet.ps1` verify the expected backend SHA-256 hashes before packaging/installing them. Direct3D 12 is installed as the initially active backend; the launcher switches backend DLLs when required.

`CreditPatch.cs` verifies supported menu hashes and rebuilds the companion archive index. The small embedded recipe contains credit differences, not complete proprietary archives.

The third-party LZX decoder retains its Ms-PL notice. Original installer source uses the root MIT license. Game data, original executables and generated guest code are excluded.
