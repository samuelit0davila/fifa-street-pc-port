Install

On the court in four steps

  1. 1

    Download the installer

    Get ReStreet Setup.exe from the latest GitHub release. You can check it with the .sha256 file next to it.

  2. 2

    Run Setup

    Pick your own FIFA Street (2012) Xbox 360 ISO and an empty folder. Already have ReStreet? Pick its folder instead: no ISO needed.

  3. 3

    Open the launcher

    Open it from the ReStreet shortcut on your desktop and press PLAY. Weaker PC? In Graphics, use 1x internal resolution.

  4. 4

    Stay up to date

    When a new version is out, the launcher shows Update. Click it: your name, server, settings and World Tour progress are kept.

FAQ

Questions and known issues

Is ReStreet official? Is it free?

It is a free fan project, not affiliated with EA, Microsoft or Xbox. You need your own copy of FIFA Street (2012) for Xbox 360.

Why do I need an ISO?

The installer reads the game's data from your own disc image. The ISO and the original game files are never included in ReStreet.

How do I update?

Open the launcher and click Update. New players download the latest Setup.exe instead.

I see small stutters on Vulkan.

Vulkan has small stutters on 2.0. Switch to Direct3D 12 in the launcher.

World Tour player portraits look scrambled.

Known issue in My Squad; a fix is in progress. "Download not available" for some World Tour teams is a harmless server message.

Can I use the mouse for skill moves?

Not yet on 2.0: the launcher option is hidden for now.

How do I leave an online match?

Press START + B. The game's own "leave this session?" question can show behind it: close it with A.

Is there chat in the game?

Chat is only in the launcher for now. In the game, use the friends Guide (F6) for invites.

Two games on one PC lose the connection.

This can happen after an invite when both games run on the same PC. It does not affect players on different PCs.

Does it work on Linux or Steam Deck?

Yes, in beta: a native Linux launcher runs the game through Proton, and online works. Download ReStreet-Linux-launcher.tar.gz from the latest release and follow the "Linux (beta)" guide in the README on GitHub. Tested on CachyOS; the Steam Deck is not tested yet.
